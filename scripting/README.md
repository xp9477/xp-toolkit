# Scripting

iOS [Scripting](https://scripting.fun) 原生 TypeScript / TSX 项目集合。

相比传统的 Scriptable，Scripting 支持真正的现代开发工作流：
- 原生 TypeScript / TSX 与 JSX 声明式界面开发
- 基于 SwiftUI 理念的原生视图体系（VStack, HStack, Capsule, Button, Link, DateLabel 等）
- iOS App Intents 原生交互支持（桌面小组件无需进入 App 即可原地静默刷新）
- iOS 18 染色（Accented / Tinted）模式原生适配
- 原生锁屏小组件 (`accessoryRectangular` / `accessoryInline`)

## 项目列表

- [ai-quota](./ai-quota/): AI 配额监控小组件，支持 SuperGrok、ChatGPT 与 Google Gemini 配额监控、原地刷新与官方 App 快速直达。
