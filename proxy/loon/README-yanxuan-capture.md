# 网易严选签到 Cookie 本地安全获取（Loon 插件）

本插件用于在手机端 Loon 本地安全捕获网易严选签到所需的必要凭据，并保存至 Loon 本地持久化存储，方便用户手动转移至青龙面板的 `yanxuan_daily_sign` 环境变量中。

---

## 插件安装链接 (Raw URL)

在 Loon 中添加插件时，可直接使用以下订阅链接：

```text
https://raw.githubusercontent.com/xp9477/xp-toolkit/main/proxy/loon/plugin/yanxuan-cookie-capture.plugin
```

## 核心安全设计

1. **严格域名与路径白名单**：
   - 目标主机：仅限 `act.you.163.com`（HTTPS 协议且仅允许默认 443 端口，拒绝 userinfo、非标准端口与 URL fragment）。
   - 监听路径：仅限以下三条上游签到活动接口：
     - `/act-attendance/task/list`
     - `/act-attendance/att/v4/index`
     - `/act-attendance/att/v3/sign`
2. **严格凭据字段白名单**：
   - 仅提取 `yx_csrf`、`yx_new_sid`、`yx_sid`、`NTES_YD_SESS` 四类必要字段，其余 Cookie 字段一律丢弃。
   - 必须同时具备 `yx_csrf` 和至少一项有效会话字段才判定登录态完整。
3. **零远程外发与零流量篡改**：
   - 不调用任何网络 API（无 `$httpClient`、无 `fetch`、无外部推送或 Bark），无公网代理暴露。
   - 原请求始终以 `$done({})` 原样透传，不影响正常网络访问。
4. **日志与通知无秘密泄露**：
   - 通知标题、副标题、通知正文以及控制台日志中**绝不输出任何 Cookie 或凭据明文**。
   - 异常捕获采用固定通用文案，不输出动态错误对象以防凭据被包含在异常信息中打印。
5. **本地存储去重与 Fail-Closed 机制**：
   - 数据写入 Loon 本地 `$persistentStore`（键名 `yanxuan_daily_sign`）。
   - 采用 Fail-Closed 设计：当存储环境不可用或写入未成功时立即终止，绝不发送假成功通知。
   - 自动比对已有本地存储，相同凭据不重复写入且不重复弹窗。

## 手机端前置设置（必须由用户在本地完成）

> **注意**：脚本与插件无法替代系统级安全配置，初次使用必须在手机端完成一次性本地设置：

1. **启用 MITM 并安装信任证书**：
   - 打开 Loon，按照 Loon 设置页面的指引生成/安装本机 CA 证书。
   - 进入 iOS 系统设置，在证书信任设置中将该 CA 证书设为完全信任。
   - 按照 Loon 设置页面提示开启 MITM 解密，并确保包含主机名 `act.you.163.com`。
2. **启用插件**：
   - 在 Loon 中添加并启用上述插件 URL。

## 凭据获取与转移至青龙

在已登录网易严选账号的 App 或浏览器中打开严选签到活动页，触发任意一条上述白名单接口。

### 主推荐方式：点击通知复制到剪贴板

1. 成功捕获后手机会收到系统横幅通知：
   - **标题**：`网易严选签到`
   - **内容**：`点击本通知复制所需配置，然后到青龙新增 yanxuan_daily_sign 环境变量`
2. **用户主动点击该通知**，Loon 会触发官方 `{ clipboard: value }` 机制将配置 JSON 写入剪贴板。
   > **安全提醒**：
   > - 脚本不会自动直接写入剪贴板，仅在用户主动点击通知时才触发。
   > - 写入剪贴板后，设备本地剪贴板以及跨设备通用剪贴板（如 iCloud 剪贴板同步）在短时间内可能包含会话凭据。
   > - 建议在复制后尽快粘贴到青龙，并在完成后复制任意普通内容覆盖剪贴板。

### 辅助方式：Loon 持久化存储查看

- 若你使用的 Loon 版本提供了持久化存储查看功能，可直接在本地存储记录中查找键名为 `yanxuan_daily_sign` 的数据并手动复制。

### 写入青龙环境变量

将复制出的 JSON 粘贴至青龙面板的“环境变量”中：
- **名称**：`yanxuan_daily_sign`
- **值**：形如 `{"cookie":"yx_csrf=...; yx_sid=...", "ua":"..."}`

## 运行限制与边界

1. **纯本地安全**：本方案坚持本机存储原则，不提供也不依赖任何公网中转服务器，凭据必须手动复制转移。
2. **会话刷新**：当严选登录态失效或在 App 端重新登录导致会话变更后，需要重新打开一次签到活动页以获取新凭据并更新青龙环境变量。
3. **只读旁路**：插件仅作为只读旁路捕获，不执行自动签到动作；实际签到任务由青龙内的 `yanxuan_daily_sign.py` 在受控网络环境下定时运行。
