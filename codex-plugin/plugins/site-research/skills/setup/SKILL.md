---
name: setup
description: 安装或诊断 Site Research 个人插件的本机浏览器配对和 Linux.do 登录连接。仅在用户要求接入、插件未连接或登录失效时使用。
---

目标是让本地 MCP 通过用户自己的 Chrome 登录只读访问 Linux.do，不索取或搬运账号凭据。

1. 定位本技能所属的插件根目录（本文件上两级目录），检查 Node.js >=22。MCP 配置启动的是同一包中的 `scripts/mcp-server.mjs`。不要为兼容而修改用户的其他 MCP。
2. 指导用户在 Chrome/Chromium 扩展页开启开发者模式，加载插件内的 `extension/`。这是用户主动安装的本机扩展，不能静默安装或声称已连接。
3. 让用户在插件根目录自己的终端运行 `npm run pair`。该命令启动 127.0.0.1:47831 的桥接并显示本机配对码。**不要替用户运行会把配对码打印到聊天的命令**。用户把码直接填入扩展设置，再点击连接。
4. 扩展打开专用 Linux.do 标签页。让用户自行登录/验证，保持 Chrome 和该标签页打开；不接管密码输入或导出 Cookie。
5. 通过 `research_status` 检查桥接，再经用户同意用 `research_account` 核对用户名。优先用用户提供的帖子链接测试。不能因为离线测试通过就声称账号实测完成。

断开：扩展设置“断开并清除配对码”；`npm run stop` 停止本机桥接。卸载流程和状态文件位置见插件 README。切换浏览器或配置文件前先断开原连接，同一桥接只接收一个活跃扩展实例。
